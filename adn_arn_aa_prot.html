🧬 De l'ADN à la Protéine

Suis les étapes : ADN → ARN → codons → acides aminés → protéine.
Puis découvre l'impact d'une mutation qui introduit un codon stop prématuré.

Rappel des règles :
1. ADN → ARN : remplace chaque base T par U (A→A, C→C, G→G, T→U)
2. ARN → Codons : regroupe les bases 3 par 3 depuis le début
3. Codon → Acide aminé : utilise le tableau ci-dessous
4. Codon stop (UAA, UAG, UGA) : la protéine s'arrête là

❌ La protéine est tronquée : le codon STOP prématuré (UAA) interrompt l'ajout d'un acide aminé sur la protéine. La protéine produite ne fait que 3 acides aminés au lieu de 5 — elle est non fonctionnelle. C'est exactement ce type de mutation qui peut provoquer des maladies génétiques.
